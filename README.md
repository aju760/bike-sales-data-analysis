# bike-sales-data-analysis
Bike Sales Data Analysis using Python, Pandas, Matplotlib and Seaborn

## Project Overview

This project analyzes 15,000 bike sales records using Python to identify patterns and insights related to bike brands, prices, mileage, engine capacity, cities and fuel types.

## Objectives

- Clean and preprocess bike sales data
- Analyze bike prices across different brands
- Analyze mileage by brand
- Identify city-wise bike distribution
- Analyze fuel type distribution
- Study the relationship between engine capacity and price
- Study the relationship between kilometers driven and price

## Data Cleaning

The dataset was cleaned using Python and Pandas.

The cleaning process included:

- Checking for missing values
- Checking and removing duplicate records
- Checking data types
- Validating numerical columns
- Preparing the cleaned dataset for analysis

## Exploratory Data Analysis

The following analyses were performed:

- Brand-wise bike count
- Brand-wise average price
- Brand-wise average mileage
- Year-wise bike distribution
- City-wise bike distribution
- Fuel type analysis
- Engine CC vs Price
- KM Driven vs Price

## Visualizations

Visualizations were created using:

- Matplotlib
- Seaborn

Charts include:

- Bar Charts
- Line Plots
- Scatter Plots
- Box Plots
- Correlation Heatmap

## Tools & Technologies

- Python

## Dataset

The dataset contains 15,000 bike records and 10 columns covering bike details such as brand, model, year, fuel type, engine capacity, price, kilometers driven, mileage and city.

## Key Insights

The analysis was used to identify:

- Differences in average bike prices across brands
- Mileage patterns across brands
- Distribution of bikes across cities
- Distribution of bikes by fuel type
- Relationship between engine capacity and price
- Relationship between kilometers driven and price

## Conclusion

This project demonstrates the use of Python for data cleaning, exploratory data analysis and data visualization. The analysis provides a structured approach to understanding bike sales data and extracting meaningful insights.
